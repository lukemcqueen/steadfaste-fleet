# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those
roles to the label vocabulary used in this repo's tracker (the fleet task-db).

The task-db has no GitHub-style label system, so these are **JSON `tags`** on a
task row (`task-db.py add ... --tags '["ready-for-agent"]'`). Read a row's tags
to recover its triage state.

| Role in skills          | Tag in task-db | Meaning                                     |
| ----------------------- | -------------- | ------------------------------------------- |
| `needs-triage`          | `needs-triage`       | Maintainer needs to evaluate this task      |
| `needs-info`            | `needs-info`         | Waiting on reporter for more information    |
| `ready-for-agent`       | `ready-for-agent`    | Fully specified, ready for an AFK agent (claimable) |
| `ready-for-human`       | `ready-for-human`    | Requires human implementation               |
| `wontfix`               | `wontfix`             | Will not be actioned                        |

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the
corresponding tag string from this table as a task-db `tag`.

_This file is generated by `/setup-matt-pocock-skills`; edit it directly to
change the vocabulary._
